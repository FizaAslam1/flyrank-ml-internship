Content Opportunity Scoring

A Data-Driven Framework for Prioritizing SEO Actions
FlyRank ML Internship Capstone • July 2026
Abstract: How can content teams identify which pages need SEO attention first? We analyzed 137,490 pages from the FlyRank search warehouse using a composite opportunity scoring model with five core features: visibility (30%), engagement (25%), CTR (20%), position (15%), and AI traffic (10%). Our analysis reveals that 89.8% of pages show 0% click-through rate despite ranking in positions 10-20, indicating poor meta/CTR optimization. Only 0.15% of pages receive AI traffic (all from ChatGPT), revealing a major AI optimization opportunity. The framework categorizes pages into six actionable archetypes and provides a repeatable, data-driven playbook for content prioritization — directional and decision-support, not causal.

1. Introduction

Content teams face a fundamental challenge: with hundreds of thousands of pages, how do you decide which pages to optimize, rewrite, or remove? Most teams rely on intuition or simple metrics like rank position alone. This approach misses critical signals like engagement, click-through rates, and AI referral potential.

This paper presents a repeatable, data-driven opportunity scoring framework built on real FlyRank search data. The framework answers one core question:

"Which page should I work on next, and what should I do with it?"

The output is a ranked action engine that categorizes pages into six actionable archetypes with specific recommendations. This enables content teams to move from reactive firefighting to strategic, data-backed prioritization.

3. Methodology

3.1 Feature Engineering

For each page, we aggregated daily performance into five core feature groups:

FeatureWeightDescription
Visibility Score30%Impressions relative to top page
Engagement Score25%GA4 engaged sessions relative to top page
CTR Score20%Click-through rate relative to top page
Position Score15%Lower position = higher score (1/(position+1))
AI Score10%AI referral sessions relative to top page

5. Limitations & Honest Framing

⚠️ Important: This analysis is directional, not causal.
  • Single-day data: The analysis uses only June 1, 2026. This is a snapshot, not a time-series analysis.
  • Sparse AI data: Only 0.15% of pages have AI referral data. The AI score component has limited statistical power.
  • Cross-sectional only: We cannot make predictions about future performance.
  • No causal claims: Correlation ≠ causation. We do not claim that optimization will improve rankings.
  • Anonymized data: All identifiers are pseudonymized. We cannot link to real websites.

Decision-support language: These recommendations are directional — they should be used as a starting point for human review, not as automated decisions.

6. Ranked Recommendations

⭐ TOP PERFORMER - Maintain
  • ✅ Monitor performance weekly for any declines
  • ✅ Keep content fresh with minor updates
  • ✅ Promote on social media for more visibility
📈 HIGH OPPORTUNITY - Optimize
  • 🔧 Improve meta titles and descriptions to boost CTR
  • 🔧 Add more relevant keywords naturally in content
  • 🔧 Update content with fresh information and examples
  • 🔧 Improve internal linking to pass authority
👀 VISIBLE BUT UNDERPERFORMING - Improve Content
  • ✏️ Rewrite introduction to better match user intent
  • ✏️ Add multimedia (images, videos, infographics)
  • ✏️ Improve readability and content structure
  • ✏️ Update with latest data and examples
🔍 LOW VISIBILITY - Build Authority
  • 📣 Build quality backlinks to this page
  • 📣 Share on relevant forums, communities, and social media
  • 📣 Create supporting content (sister articles, pillar pages)
  • 📣 Improve site speed and mobile experience
📉 DEEP RANKING - Consider Prune/Merge
  • 🗑️ Priority: Merge with similar higher-authority content
  • 🗑️ Redirect to more authoritative page
  • 🗑️ Delete if completely irrelevant or outdated
⚠️ UNDERPERFORMING - Review Content
  • 🔍 Review if content meets user search intent
  • 🔍 Check for outdated or incorrect information
  • 🔍 Add more comprehensive coverage of the topic
  • 🔍 Consider complete rewrite with better structure
